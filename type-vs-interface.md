# The Difference between `type` aliases and `interface` in typescript

These two are used for define the structure and shape of the data in typescript. but they are used differently.

- **interface** this is mainly use to define the structure of object and class.
- **type aliases** this is also use to define the object structure, but this is more flexible

I prefer `interface` when defining object structure, specially when need for class and object  need extension,
But i use `type` when using unions, tupples or need more flexibility.
